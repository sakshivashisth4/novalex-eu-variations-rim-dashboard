\# Dashboard Page Guide

\#\# Purpose

This document explains each Power BI dashboard page in the Novalexib EU Variations RIM Dashboard.

\#\# Page 1: Drug Profile

\#\#\# Purpose

The Drug Profile page gives users a product-level overview of Novalexib.

\#\#\# Main Content

\- Product name  
\- Therapeutic area  
\- Health authority  
\- Procedure type  
\- MAA approval date  
\- Current lifecycle stage  
\- Current regulatory status  
\- Regulatory approval status gauge  
\- Key lifecycle milestones  
\- Current activity and regulatory focus

\#\#\# Business Question Answered

What is the current regulatory status of Novalexib?

\#\# Page 2: Executive Overview

\#\#\# Purpose

This page provides a management-level summary of the overall submission portfolio.

\#\#\# Main Visuals

\- KPI cards for total submissions, archived submissions, under assessment submissions, pending implementation, overdue implementation, and total agency queries  
\- Donut chart for submission status  
\- Bar chart for variation category split  
\- Stacked bar for submission status by variation category  
\- Risk profile by status  
\- Overdue implementation watchlist  
\- Publishing and archive health summary

\#\#\# Business Question Answered

What is the overall health of the Novalexib regulatory portfolio?

\#\# Page 3: Submission Pipeline

\#\#\# Purpose

This page tracks submission timelines, delays, and lifecycle movement.

\#\#\# Main Visuals

\- Gantt chart showing planned submission date to implementation date  
\- Scatter chart showing submission delay vs assessment duration  
\- Horizontal bar chart showing implementation overdue days  
\- Funnel chart showing submission status pipeline  
\- Active submission table

\#\#\# Business Question Answered

Which submissions are delayed, active, or taking longest to progress?

\#\# Page 4: Agency Query Intelligence

\#\#\# Purpose

This page analyses health authority query patterns and response performance.

\#\#\# Main Visuals

\- Clustered bar chart for queries by type and round  
\- Matrix heat map for CTD module by query round  
\- Average days to respond by query round  
\- Treemap for response owner workload  
\- Stacked bar for query subcategory by submission  
\- Query detail table

\#\#\# Business Question Answered

Which submissions, CTD modules, query topics, and owners are driving agency query burden?

\#\# Page 5: Document Readiness & Lifecycle

\#\#\# Purpose

This page tracks content plan readiness and document review performance.

\#\#\# Main Visuals

\- Matrix by submission and CTD module  
\- Average days in review by document type  
\- Document lifecycle Gantt  
\- Document ownership donut  
\- Document status slicers

\#\#\# Business Question Answered

Which documents are approved, in review, delayed, or creating bottlenecks?

\#\# Page 6: Publishing & Archive Pipeline

\#\#\# Purpose

This page tracks eCTD publishing, validation, final package readiness, and archive QC.

\#\#\# Main Visuals

\- KPI cards for submitted packages, validation passed, archived packages, pending QC, and archive not started  
\- Archive QC matrix  
\- Document availability flag table  
\- Publishing readiness bar chart  
\- Validation status donut

\#\#\# Business Question Answered

Are submitted packages publishing-ready, validated, archived, and QC-complete?

\#\# Page 7: EMA Variation Reference Intelligence

\#\#\# Purpose

This page provides reference intelligence from the simulated EMA variation master database.

\#\#\# Main Visuals

\- Variation category by risk level heat map  
\- Preapproval required by variation type  
\- Treemap of variation type by category  
\- Required documents visual  
\- Variation category and risk slicers

\#\#\# Business Question Answered

Which variation types carry the highest regulatory burden and document requirements?

\#\# Page 8: Drug Lifecycle Timeline

\#\#\# Purpose

This page visualises the full development and post-authorisation lifecycle timeline.

\#\#\# Main Visuals

\- Drug lifecycle Gantt chart  
\- Milestone table  
\- Category and status slicers  
\- Current status marker  
\- Lifecycle activity by year

\#\#\# Business Question Answered

Where is Novalexib in its overall regulatory lifecycle from development through long-term maintenance?
