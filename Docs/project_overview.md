\# Project Overview: Novalexib EU Variations RIM Dashboard

\#\# Project Title

\*\*Novalexib EU Variations RIM Dashboard\*\*

\#\# Objective

This project simulates a Veeva Vault RIM-style regulatory operations dashboard for a fictional EU-approved product, \*\*Novalexib\*\*. The project demonstrates how post-authorisation variation submissions, content planning, document lifecycle management, agency queries, publishing, and archive tracking can be structured and visualised using Excel, Python, and Power BI.

The purpose of the project is to showcase regulatory affairs knowledge, EU variation lifecycle understanding, data structuring, workflow mapping, and dashboard development skills.

\#\# Product Context

Novalexib is a fictional EU-approved medicinal product. The simulated product received EU marketing authorisation on \*\*15-Mar-2022\*\* through the \*\*Centralised Procedure\*\*. The first post-authorisation variation was submitted on \*\*15-Jun-2024\*\*.

The project focuses on post-authorisation lifecycle management, including:

\- Type IA / IAIN variations  
\- Type IB variations  
\- Type II variations  
\- Implementation tracking  
\- Agency query management  
\- CTD content readiness  
\- eCTD publishing readiness  
\- Archive QC and dossier completeness

\#\# Business Problem

Regulatory teams often manage multiple submissions, documents, query rounds, and implementation deadlines across different trackers. Without a centralised view, it becomes difficult to identify:

\- Which submissions are overdue  
\- Which variation types carry the highest risk  
\- Which CTD modules generate most agency queries  
\- Which documents are still in review  
\- Whether final published packages are archived correctly  
\- Which teams or owners carry the highest workload

This project solves that problem by creating an integrated regulatory dashboard.

\#\# Key Insights Simulated

The dashboard is designed to show:

\- Novalexib is approved and currently in post-authorisation lifecycle management.  
\- Most submissions are completed and archived.  
\- Type II CMC/Quality variations carry the highest regulatory risk.  
\- Agency queries are concentrated in quality, CMC, stability, GMP, and impurity topics.  
\- Document review cycles are longer for complex Type II submissions.  
\- Publishing readiness and archive QC status can be monitored centrally.  
\- Implementation overdue submissions require management attention.
